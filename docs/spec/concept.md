# 宴 -EN- 企画書（コンセプト定義）

- 版: v1.0
- 日付: 2026-08-21
- 位置づけ: 詳細仕様書（[overall.md](overall.md)）の上位にあたる「なぜ作るか・誰のためか」の定義。機能仕様は overall.md を正とする

## 1. 課題

**一人で飲むのはさみしい。でも、いま一緒に飲んでくれる相手を見つける手段がない。**

- 飲みたい夜に限って、友人は忙しい・時間が合わない・誘うほどでもない
- SNS で「誰か飲もう」と発信するのはハードルが高く、返ってくる保証もない
- 既存のオンライン通話ツール（Zoom / Discord 等）は「すでに約束した知り合いと話す」ための道具であり、**相手を見つけるところ**を解決しない
- ランダムチャット系サービスは1対1・雑談文脈で、「飲み会のゆるい複数人の空気」にならない

## 2. ペルソナ

### メイン: ソロ飲みの社会人

- 20〜30代、一人暮らし。金曜22時、家で一人で飲んでいる
- オンライン通話には慣れているが、自分から人を誘うのは苦手
- 知らない人と話すこと自体は嫌いではない。ただし「顔出し必須」「1対1」は重い
- 求めているもの: **今すぐ、ゆるく、複数人の飲みの場に混ざれること**

### サブ: 集まりたいが場所がない知り合いグループ

- 大学の友人・元同僚など、たまにオンラインで飲む仲間
- ツールを立ち上げて URL を配って…という段取りが毎回面倒
- 求めているもの: **合言葉ひとつで集まれる手軽な場**と、間が持つ遊び

## 3. 提供価値（ソリューション）

「飲み相手が見つかる場」と「場が温まる仕掛け」をワンセットで提供する。

### 3つの入り口（マッチング）

| 入り口 | 使う人 | 体験 |
|---|---|---|
| ランダムマッチ | メインペルソナ | 「いますぐ飲む」を押すと、同じくひとり飲みの誰かと自動で相席になる |
| 公開ルーム一覧 | メインペルソナ | 雰囲気を見て入るルームを選ぶ（オープン入室 or ホスト承認制） |
| 合言葉ルーム | サブペルソナ | 合言葉を決めて共有するだけで知り合いが集まれる |

### 場が温まる仕掛け（サブ要素）

- **趣味タグ**: 運営プリセットから選ぶ興味関心タグ。参加者の名前の横に見え、共通の話題のきっかけになる。ランダムマッチでは共通タグが多い人を優先して相席させる
- **パーティゲーム**（大喜利・以心伝心・クイズ + 自作ゲーム）: 初対面の沈黙を壊す共通の話題装置。ゲームが主役なのではなく、会話を始めるための道具
- **場回し bot**: ルールベースのファシリテーター。挨拶・話題振り・ゲーム提案・沈黙の解消を担い、「誰も口火を切らない」問題を防ぐ
- **VC / カメラ**: 音声中心。カメラは全ルーム初期OFF（顔出しの重さを排除）

## 4. 競合との違い

| | 相手探し | 複数人の飲み文脈 | 場を温める仕掛け |
|---|---|---|---|
| Zoom / Discord | ✗（知り合い前提） | △ | ✗ |
| ランダムチャット系 | ○ | ✗（1対1・雑談） | ✗ |
| **宴 -EN-** | **○（3つの入り口）** | **○（飲み会の場として設計）** | **○（ゲーム + bot）** |

一言で: **「会いたい人がいなくても飲み会が始まる」のは宴だけ。**

## 5. 安全に関する基本姿勢

見知らぬ人同士を引き合わせるサービスであるため、以下を企画レベルの前提とする（詳細は overall.md §3.7 / §3.8）:

- カメラは全ルーム初期OFF。他者に見えるのはあだ名とプリセット趣味タグのみ（自由記述プロフィール・DM なし）
- キック・ブロック・通報の導線を常設。ワンタップで退出できる
- 対象年齢は20歳以上を想定（自己申告）
- bot は外部 AI API を使わないルールベース実装とし、発話内容はすべて運営が用意したテンプレートに限る

## 6. 発表デモの軸

1. ペルソナ提示: 「金曜22時、家で一人で飲んでいる」
2. 「いますぐ飲む」→ ランダムマッチで相席になるまでを実演
3. 沈黙 → bot が話題を振る → 大喜利1ラウンドで場が温まる流れを見せる
4. 合言葉ルームで知り合い同士の利用も見せる（サブペルソナ）
5. 締め: 「会いたい人がいなくても飲み会が始まる」
