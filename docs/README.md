# docs — 仕様書・設計書

このフォルダにはプロジェクトの仕様書・設計書を置く。

## 構成

```
docs/
├── README.md   … このファイル（構成の説明）
├── spec/       … 仕様書（何を作るか: 要件・機能・画面・制約）
│   ├── overall.md   … 全体仕様書（サイト全体の要件・ページ構成・共通ルール）
│   └── <page>.md    … ページ別仕様書（例: engine.md, login.md, list.md, submit.md）
├── design/     … 設計書（どう作るか: 構成・API・データ・処理フロー）
│   ├── overall.md   … 全体設計書（ディレクトリ構成・API 仕様・データ設計・担当表）
│   └── <page>.md    … ページ別設計書
└── testing/    … 自動テストで担保できない部分の手動テスト手順書
    └── vc-manual.md … VC（音声・カメラ）の手動確認手順
```

## 運用ルール

- 実装に着手する前に、該当する仕様書・設計書を作成／更新する。
- 全体に関わる変更（API 仕様・共通データ形式など）は `overall.md` を更新し、PR で全員がレビューできるようにする。
- ページ別ドキュメントの命名はページのディレクトリ名に合わせる。
