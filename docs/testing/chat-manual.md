# テキストチャット 手動テスト項目（§3.9）

チャット機能（`public/room/chat.js` + 開発用動作確認ページ）の手動テストチェックリスト。

## 前提条件

- `deno task dev` でサーバーを起動し、`http://localhost:8000` をブラウザで **2窓**（例: 通常ウィンドウ + シークレットウィンドウ、またはタブ2つ）開く
- 窓A でニックネームを入れて「招待制ルームを作成」、窓B で参加コードを入れて「参加」し、同じルームに入室した状態にする
- DevTools（F12）のコンソールを開いておく（エラー監視・bot 表示テスト用）

## チェックリスト

### 基本の送受信

- [ ] 窓A で本文を入力し「送信」ボタンを押すと、**窓A・窓B の両方**のチャット履歴に `時刻 ニックネーム 本文` が表示される（自分にも表示される）
- [ ] 入力欄で Enter キーを押しても同様に送信される（日本語入力の**変換確定の Enter では送信されない**こと）
- [ ] 送信後、入力欄が空になる
- [ ] 自分の発言に薄い背景色（`chat-self`）が付き、他人の発言と見分けられる
- [ ] 新着があると履歴が最下部まで自動スクロールする（履歴が `#chat-log` の高さを超えた状態で確認）

### 文字数の境界

- [ ] **200文字ちょうど**の本文が送信できる（例: DevTools コンソールで `"あ".repeat(200)` をコピーして貼り付け）
- [ ] **201文字**は送信されず、エラー表示が出る
  - 入力欄には `maxlength="200"` があり貼り付けでも 200 文字に切られるため、DevTools の Elements で `#chat-text` の `maxlength` 属性を一時的に削除してから `"あ".repeat(201)` を貼り付けて送信する
  - 期待: WS 送信は行われず（通信ログに `→ {"t":"chat",...}` が出ない）、「チャットは200文字以内で入力してください」が表示される
- [ ] 絵文字（サロゲートペア）は**コードポイント単位**で数えられる（例: `maxlength` を外して `"😀".repeat(200)` は送信できる ※UTF-16 では 400 単位だがコードポイントでは 200）

### 空入力・制御文字

- [ ] 空文字のまま送信しても何も送られない（通信ログに出ない）
- [ ] 空白のみ（半角/全角スペース・タブ）を入力して送信しても何も送られない
- [ ] 制御文字を含む本文は送信されずエラー表示が出る（DevTools コンソールで `document.getElementById("chat-text").value = "a\u0007b"` をセットして送信ボタンを押す。`\u0007` は実際には制御文字 BEL に展開して入力する: `"a" + String.fromCharCode(7) + "b"`）

### レート制限

- [ ] 10秒以内に6件送ると、**6件目**でエラー欄に `RATE_LIMITED` が表示される（1〜5件目は届く）
- [ ] しばらく待ってから送ると再び送信できる

### 履歴の復元・上限

- [ ] 窓B を**再読み込み**して再接続すると、直近のチャット履歴が復元される（古い順）
- [ ] 発言がある状態で**3人目が途中入室**すると、入室時点で履歴が見える
- [ ] 101件以上発言すると、表示は**直近100件**に丸められる（DevTools コンソールで一括送信して確認可:
  `for (let i = 1; i <= 105; i++) Chat.handleServerMessage({ t: "chat", message: { id: "t" + i, playerId: null, nickname: "test", text: "msg " + i, at: Date.now(), bot: false } })`
  → `Chat.getState().messages.length` が `100`、表示の先頭が `msg 6` になる)

### 退室・キック

- [ ] 「退室」ボタンを押すとチャット欄が非表示になり、再入室したとき古いルームの履歴が残っていない（履歴はサーバーのスナップショットから再取得される）
- [ ] キックされた側（`kicked` 受信）でもチャット履歴がクリアされる

### XSS 検証（§3.8）

- [ ] `<img src=x onerror=alert(1)>` を送信 → **文字列としてそのまま表示**され、alert は実行されない・画像リクエストも発生しない
- [ ] `</li><script>alert(1)</script>` を送信 → 文字列としてそのまま表示され、実行されない
- [ ] `<b>bold</b>` を送信 → 太字にならず、タグが文字として見える
- [ ] ニックネームに `<i>x</i>` を含めて入室し発言 → ニックネームも文字列のまま表示される（サーバー側の入力規則で弾かれる場合はその旨を記録）

### 表示崩れ

- [ ] スペースを含まない長い単語（例: `"W".repeat(200)`）を送っても、チャット欄が横に伸びずに折り返される（崩れる場合は既知の問題として記録）
- [ ] 絵文字・サロゲートペア（`😀🎉👨‍👩‍👧‍👦`）を含む本文が正しく表示される

### bot 表示

サーバー側の bot（§3.10）は未実装のため、DevTools コンソールから受信をシミュレートして確認する:

```js
Chat.handleServerMessage({
  t: "chat",
  message: {
    id: "bot-test-1",
    playerId: null,
    nickname: "しゅんぴ",
    text: "こんにちは！",
    at: Date.now(),
    bot: true,
  },
});
```

- [ ] ニックネームの前に `bot` バッジが付き、通常の発言と見分けられる
- [ ] `playerId: null` でもエラーにならず、自分の発言用の背景色は付かない

### コンソールエラー

- [ ] 上記すべての操作を通して、ブラウザの DevTools コンソールに JavaScript エラーが出ていない
